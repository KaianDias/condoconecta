# Frontend

Pasta destinada à interface web do CondoConecta (React, conforme definido na seção 3.1 do PGCS).

## Telas previstas

- Calendário de reserva de áreas comuns
- Mural de avisos
- Abertura e acompanhamento de chamados
- Votação de assembleia
- Painel (dashboard) do síndico
- Consulta de status financeiro por unidade
