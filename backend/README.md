# Backend

Pasta destinada à API REST do CondoConecta (Node.js/Express, conforme definido na seção 3.1 do PGCS).

## Responsabilidades previstas

- Endpoints de reserva de áreas comuns
- Endpoints de avisos e comunicados
- Endpoints de chamados de manutenção
- Endpoints de votação de assembleia
- Endpoints do módulo financeiro (taxa condominial)
- Autenticação de síndico e morador

## Convenções

Os testes automatizados ficam em `backend/tests`, seguindo a política de qualidade descrita na seção 5.3 do PGCS.
